# 360度評価システム デスクトップアプリ

各事業所の共有PCにインストールして使う、評価入力用のクライアントアプリです(要件定義書 5章・7.3)。
Electron製で、360度評価API(`../src/`)とHTTPS通信するだけで、Googleスプレッドシートや
Googleアカウントの認証情報はこのアプリ自身には一切持ちません。

## できること

- ログイン(社員番号・パスワード)
- 評価対象者一覧の表示、評価済み/未評価の進捗表示(F-02, F-06)
- 通常評価(大項目2×小項目5+自由記述2)・代表向け簡易評価(自由記述1のみ)の入力(F-03, F-10)
- 評価結果の送信、二重送信時の上書き確認(F-04)

## セットアップ

```bash
cd desktop-app
npm install
```

初回起動時、`config.example.json` から `config.json` が自動でコピーされます。
`config.json` を開き、`src/` をデプロイして得られたWeb アプリのURLに書き換えてください。

```json
{
  "apiBaseUrl": "https://script.google.com/macros/s/xxxxxxxx/exec"
}
```

`src/` のデプロイ手順はリポジトリ直下の `README.md` を参照してください。まだデプロイしていない場合、
ログイン時に接続エラーになります。

## 起動

```bash
npm start
```

## マスタデータ(評価項目・評価期間)の更新について

評価基準(部門マスタ・部署マスタ)や評価期間は、このアプリの中には一切持たせていません。
ログイン時に毎回 `getMaster` を呼び出してスプレッドシートの最新内容を取得する設計のため、
**評価専用マスタのスプレッドシートを編集すれば、次にこのアプリでログイン(または再ログイン)した
時点で自動的に反映されます**。アプリ自体の再配布・再インストールは不要です(要件定義書 7.5)。

ログインしたまま長時間開きっぱなしにする場合、一覧画面を再読み込みしたい時は一度ログアウトして
再ログインしてください(トークンは8時間で自動的に失効します)。
